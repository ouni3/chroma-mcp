# Context

## Current Status
The project is a fully functional MCP server for Chroma vector database, currently at version 0.2.6. It is deployed via Docker on a remote server (192.168.0.104) and successfully connected to the ChromaDB instance there (192.168.0.104:8012). The server exposes the MCP SSE endpoint on port 8013.

## Recent Achievements
- **Remote Deployment**:
    - Created `docker-compose.remote.yaml` specifically for remote server deployment, mapping the MCP server to port **8013** to avoid conflicts.
    - Successfully deployed to `192.168.0.104` and verified connectivity.
- **E2E Verification**:
    - Updated and executed `tests/e2e_live.py` to target the remote deployment at `http://192.168.0.104:8013/sse`.
    - Confirmed full lifecycle functionality (Create, Add, Query, Delete) works correctly in the remote environment.
- **Compatibility Fix**: Downgraded the Docker image's `chromadb` client dependency to `1.0.16` to match the user's host environment and server version (1.0.20), solving a critical issue where collections were visible but data was unreadable.
- **Gemini Embedding Integration**:
    - Confirmed that the user's data (in `techChat` collection) uses 3072-dimensional embeddings generated by `gemini-embedding-001`.
    - Modified `src/chroma_mcp/server.py` to default to `openai` embedding function (configured for Gemini) for `chroma_query_documents`, `chroma_add_documents`, and `chroma_update_documents`. This ensures seamless query compatibility without manual parameter specification.
    - Implemented fallback logic to handle "Embedding function conflict" errors gracefully.
- **Retrieval Validation**: Verified successful semantic retrieval from the `techChat` collection using the query "链表".
- **Keyword Generation Feature**:
    - Implemented `chroma_generate_keywords` tool.
    - Uses K-Means clustering on document embeddings to identify topic clusters.
    - Uses **Hybrid Extraction (TextRank + TF-IDF)** to maximize keyword coverage (Core Themes + Specific Terms).
    - Validated with unit tests (`tests/test_keywords.py`) and live test (`tests/test_keywords_live.py`) against the `techChat` collection.
    - Successfully extracted 52 keywords from `techChat`, including concepts like "Agent", "GCP", "梯度", "费曼", "AutoGen", "指针" (Linked List), "Memory".
